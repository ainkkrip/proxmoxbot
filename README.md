# Telegram Proxmox & VM Manager

Бот для удобного управления вашей главной нодой (Proxmox) и виртуальными машинами (на базе Ubuntu) прямо из Telegram.

## Возможности
- Мониторинг ресурсов (CPU, RAM, Disk) для Ноды (через `psutil`) и для VM (парсинг через SSH / QEMU Guest Agent).
- **Разделение прав доступа (Роли):**
  - **Администратор (`admin_ids`):** полный доступ к Ноде и всем виртуальным машинам, перезагрузка/выключение ноды и любых ВМ, выполнение команд `.console <команда>` на Ноде или `.console --vm <id> <команда>` на любой ВМ.
  - **Гость / Друг (`guest_ids`):** доступ строго к одной назначенной ВМ (например, `vm2`). Получает мониторинг своей машины на `/start`, кнопки `Reboot VM`, `Shutdown VM` и `Обновить`. Команды `.console <команда>` автоматически выполняются внутри его ВМ с правами root без доступа к ноде и чужим машинам.
- Выполнение терминальных команд через QEMU Guest Agent (работает напрямую через гипервизор, даже если на ВМ упал SSH-сервер или недоступна сеть).
- Безопасность: бот блокирует любых посторонних пользователей, не указанных в конфиге.

## Инструкция по запуску

1. **Установите Python 3.10+** на вашу главную ноду (Proxmox), если его там еще нет:
   ```bash
   apt update
   apt install python3 python3-pip python3-venv
   ```

2. **Скопируйте файлы на сервер** в удобную папку.

3. **Создайте виртуальное окружение и установите зависимости:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

4. **Настройте конфигурацию:**
   Откройте файл `config.yaml` и укажите там:
   - Токен вашего бота (от @BotFather).
   - Ваш Telegram ID (узнать можно у бота @userinfobot). Без него вы не сможете управлять ботом.
   - Данные для подключения к вашим VM (IP-адреса локальной сети, логины, пароли).

5. **Запустите бота в фоновом режиме (через screen):**
   Виртуальное окружение (venv) никак не мешает `screen`, они отлично работают вместе! Чтобы бот продолжал работу после закрытия консоли:
   
   Создайте новую сессию:
   ```bash
   screen -S tgbot
   ```
   Активируйте окружение и запустите бота:
   ```bash
   source venv/bin/activate
   python3 bot.py
   ```
   Теперь нажмите `Ctrl+A`, а затем `D`, чтобы свернуть сессию (свернуть screen). Бот продолжит работать в фоне!
   Чтобы вернуться в нее позже, напишите `screen -r tgbot`.
   
   *(Если вы принципиально не хотите использовать venv и хотите ставить библиотеки глобально, используйте `pip install -r requirements.txt --break-system-packages`, но вариант venv + screen считается самым правильным).*
